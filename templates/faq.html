Frequently Asked Questions

Find answers to common questions about phishing emails, artificial intelligence, email analysis, and this security system.

What is phishing?

+

Phishing is a type of cyber attack where attackers attempt to trick people into revealing sensitive information such as passwords, financial information, or account credentials.

What does this project do?

+

This project is an AI-based phishing email detection system. It analyzes the content of an email and predicts whether the email is likely to be phishing or legitimate.

How does the AI detect phishing emails?

+

The system uses machine learning and TF-IDF text analysis. The email text is converted into numerical features and processed by the trained machine learning model.

What is TF-IDF?

+

TF-IDF stands for Term Frequency-Inverse Document Frequency. It is a text-processing technique that helps identify important words and phrases in documents.

What machine learning algorithm is used?

+

The project uses Logistic Regression together with a TF-IDF vectorizer to classify email messages.

Can the system guarantee that an email is safe?

+

No. Machine learning predictions are not a guarantee. The result should be treated as a security indicator. Users should also verify suspicious emails independently.

What should I do if an email is detected as phishing?

+

Avoid clicking links or opening unexpected attachments. Do not provide passwords, OTPs, or financial information. Verify the request through an official communication channel.

Does the system store analyzed emails?

+

The application records prediction history so that administrators can review previous analyses through the administration dashboard.

Who can access the administration dashboard?

+

The administration area is protected by an admin login. Authorized users can access the dashboard, detection history, and model performance information.

Can I analyze an email without opening the admin dashboard?

+

Yes. The Email Analyzer page provides a dedicated interface for submitting an email for phishing analysis.
